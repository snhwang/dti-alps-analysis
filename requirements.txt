# Dependencies for the analysis scripts in scripts/.

# Minimum versions, not exact ones. The reported results were produced on
# Python 3.14.2 with pandas 3.0.3, numpy 2.4.6, scipy 1.17.1, nibabel 5.4.2,
# matplotlib 3.10.9 and statsmodels 0.14.6, but pinning those exactly makes the
# file unusable on a different Python. Nothing here depends on
# version-specific behaviour.

pandas>=2.0
numpy>=1.24
scipy>=1.11

# NIfTI reading. Needed by any script that touches image data rather than a
# cached CSV, which is about a third of them.
nibabel>=5.1

# Figures only.
matplotlib>=3.7

# Mixed models and clustered standard errors, used by reliability_analysis.py
# and the covariate models.
statsmodels>=0.14

# Required only by the vendored reference LD-ALPS implementation, which uses
# DBSCAN to reject outlier voxels. Nothing else here imports it, so skip it
# unless you are running run_ld_alps.py.
scikit-learn>=1.3

#       uv pip install -e dti-alps-refined
#
#   tn_alps.py imports an internal pipeline module inside a try block. The
